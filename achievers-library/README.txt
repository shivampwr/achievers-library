ACHIEVERS LIBRARY WEBSITE — QUICK START

1. Extract this ZIP.
2. Open the extracted "achievers-library" folder in VS Code:
   File > Open Folder > select achievers-library
3. In VS Code choose Terminal > New Terminal.
4. Run these commands one at a time:
   npm install
   npm run dev
5. Open the local address shown in the terminal (normally http://localhost:5173).

IMPORTANT:
- This is a front-end starter website.
- Seat selection is an enquiry preview only. It does NOT reserve a seat or save data.
- Facility descriptions are starter copy and must be confirmed before publishing.
- Contact number and fees can be added when supplied.
